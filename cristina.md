## Selected work

### Anzuelo: social lead finder and content hub

A Python agent searches seven platforms, scores each lead with Claude Haiku using prompt caching, and flags content gaps into Supabase. A Next.js 16 dashboard adds a content studio that generates posts and visuals through chained Visual Director and FLUX image agents. No automatic sending, by design.

Ask me about: prompt caching for cost control, multi-agent image pipelines, human-in-the-loop design.

- Live: https://anzuelo.vercel.app

### MujerTech Bootcamp

A bilingual learning platform I built solo, from data model to deploy: Next.js App Router, next-intl, Supabase magic-link auth, strict TypeScript and a role-gated admin. It powers a 16-week AI and business bootcamp for women entrepreneurs in Latin America. Spanish by default, with an English transcription. Live with 25 learners.

Ask me about: i18n in Next.js, Supabase auth and RLS, designing curriculum for non-technical learners.

- Live: https://bootcamp.mujertech.org

### Nouvie: order and inventory system

Order-management admin for a regulated, document-heavy business (a Colombian cleaning products company). Next.js, Prisma and Supabase, with PDF invoice generation, Excel export and role-based access. Running in production.

Ask me about: document pipelines, role-based access, building for non-technical owners.

- Live: https://www.nouvie.co/

### Picas y Fijas (Bulls and Cows)

A code-breaking logic game in English and Spanish. Played by 1,092 people across 177 cities.

- Live: https://www.picasyfijas.com/

### Sazón Mexican Bot

A conversational assistant for discovering authentic Mexican recipes: bilingual chat, semantic search, recipe scaling and substitutions. Next.js and TypeScript front end, with a Python FastAPI back end using LangChain, GPT-4o-mini and FAISS.

Ask me about: retrieval with FAISS, bilingual chat, splitting a Next.js front end from a Python API.

- Live: https://sazonbot.vercel.app/
